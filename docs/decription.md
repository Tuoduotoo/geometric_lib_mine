# общее описание решения
Функции площади и периметра для круга, прямоугольника, квадрата, треугольника.
# описание каждой функции с примерами вызова
## круг 
### площадь
def area(r):
Вычисляет площадь круга по его радиусу.

Площадь круга вычисляется как π * r².

Args:
   * r (float): Радиус круга.

Returns:
   * float: Площадь круга.

Example:
   * >>> area(1)
    3.141592653589793

### периметр
def perimeter(r):
Вычисляет длину окружности (периметр круга) по радиусу.

Длина окружности вычисляется по формуле C = 2 * π * r.
Функция принимает радиус и возвращает удвоенное
произведение радиуса на число π.

Args:
   * r (float): Радиус круга, должен быть неотрицательным.

Returns:
   * float: Длина окружности, выраженная числом с плавающей точкой.

Example:
   * >>> perimeter(1)
    6.283185307179586
   * >>> perimeter(2)
    12.566370614359172

## треугольник 
### площадь
def area(a, h): 
Вычисляет площадь треугольника через сторону и высоту.

Площадь треугольника вычисляется как половина произведения
стороны на высоту, проведённую к этой стороне:
S = (a * h) / 2.

Args:
   * a (float): Длина стороны треугольника (основание).
   * h (float): Высота, проведённая к этой стороне.

Returns:
   * float: Площадь треугольника.

Example:
   * >>> area(4, 3)
    6.0
   * >>> area(10, 5)
    25.0

### периметр
def perimeter(a, b, c): 
Вычисляет периметр треугольника по трём сторонам.

Периметр треугольника вычисляется как сумма длин всех
его сторон: P = a + b + c.

Args:
   * a (float): Длина первой стороны.
   * b (float): Длина второй стороны.
   * c (float): Длина третьей стороны.

Returns:
   * float: Периметр треугольника.

Example:
   * >>> perimeter(3, 4, 5)
    12
   * >>> perimeter(6, 6, 6)
    18

## прямоугольник
### площадь
def area(a, b): 
Вычисляет площадь прямоугольника.

Площадь прямоугольника вычисляется как произведение
его длины и ширины: S = a * b.

Args:
   * a (float): Длина прямоугольника.
   * b (float): Ширина прямоугольника.

Returns:
   * float: Площадь прямоугольника.

Example:
   * >>> area(2, 3)
    6
   * >>> area(5, 4)
    20

### периметр
def perimeter(a, b): 
Вычисляет периметр прямоугольника.

Периметр прямоугольника вычисляется как удвоенная
сумма его длины и ширины: P = 2 * (a + b).

Args:
   * a (float): Длина прямоугольника.
   * b (float): Ширина прямоугольника.

Returns:
   * float: Периметр прямоугольника.

Example:
   * >>> perimeter(2, 3)
    10
   * >>> perimeter(5, 4)
    18

## квадрат
### площадь
def area(a):
Вычисляет площадь квадрата.

Площадь квадрата вычисляется как квадрат длины его стороны:
S = a². Функция принимает сторону и возвращает её произведение
на саму себя.

Args:
   * a (float): Длина стороны квадрата.

Returns:
   * float: Площадь квадрата.

Example:
   * >>> area(2)
    4
   * >>> area(5)
    25

### периметр
def perimeter(a):
Вычисляет периметр квадрата.

Периметр квадрата вычисляется как произведение длины его
стороны на 4: P = 4 * a. Функция принимает сторону и
возвращает её учётверённое значение.

Args:
   * a (float): Длина стороны квадрата.

Returns:
   * float: Периметр квадрата.

Example:
   * >>> perimeter(2)
    8
   * >>> perimeter(5)
    20
